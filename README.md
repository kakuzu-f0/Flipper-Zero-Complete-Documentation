# Flipper Zero Complete Documentation

📚 **Comprehensive documentation compilation for Flipper Zero** - covering development, applications, hardware, protocols, and utilities.

## 📖 Overview

This repository contains a complete, well-structured compilation of Flipper Zero documentation, consolidating 37 individual documentation files into a single comprehensive guide. Perfect for developers, users, and enthusiasts looking for detailed information about Flipper Zero capabilities.

## 🚀 Features

- **📦 All-in-One**: Single comprehensive file with all Flipper Zero documentation
- **🔧 Development Guide**: FBT build system, app development, debugging
- **📡 Protocol Coverage**: Sub-GHz, Infrared, NFC, RFID, and more
- **⚙️ Hardware Info**: Expansion modules, pinouts, specifications
- **🛠️ Tools & Utilities**: BadUSB scripts, converters, custom applications
- **📋 Well-Structured**: Table of contents, cross-references, organized sections

## 📚 Main Documentation Sections

### 1. Development & Build System
- **Flipper Build Tool (FBT)**: Build system, targets, VSCode integration
- **Hardware Targets**: Different hardware configurations
- **Unit Tests**: Testing framework and procedures

### 2. Applications & Plugins
- **FAM (Flipper App Manifests)**: App configuration and dependencies
- **FAP (Flipper App Package)**: External app development
- **Asset Packs**: Custom animations and icons

### 3. Hardware & Protocols
- **Expansion Module Protocol**: External hardware communication
- **FuriHalBus API**: Peripheral bus management
- **Debugging Systems**: Runtime checks and debugging

### 4. Radio & Sub-GHz
- **Supported Protocols**: 60+ manufacturer protocols
- **File Formats**: .sub files, RAW data, BIN_RAW
- **Counter Modes**: Rolling code customization
- **Remote Programming**: Create new remotes for various systems

### 5. Infrared
- **File Formats**: .ir files, test files
- **Universal Remotes**: TV, audio, AC, projectors
- **Capture Techniques**: Best practices for recording

### 6. NFC & RFID
- **File Formats**: All NFC and RFID card types
- **Supported Protocols**: Mifare, DESFire, Ultralight, etc.
- **RAW Data Reading**: Advanced card analysis

### 7. Tools & Utilities
- **BadUSB**: Advanced scripting capabilities
- **MultiConverter**: Unit conversion tool
- **NRF24**: 2.4GHz radio protocols
- **Sentry Safe**: Security research tools

### 8. System & Debugging
- **Key Combinations**: Recovery and DFU modes
- **OTA Updates**: Over-the-air update process
- **Custom Names**: Device personalization
